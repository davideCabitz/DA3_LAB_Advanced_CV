# DA3_LAB_Advanced_CV

Reproduction of **Depth Anything 3** (Lin et al., arXiv:2511.10647) for the Advanced Computer Vision
lab: our own implementation of the paper's baseline (single DINOv2 ViT with input-adaptive cross-view
attention, camera tokens, Dual-DPT depth + ray head, camera head, depth-ray losses), reduced-scale
training, the Sec. 6 benchmark, and a Blender-ready reconstruction demo. **All runs happen on Kaggle.**

- **Run the baseline step by step:** [docs/BASELINE_RUNBOOK.md](docs/BASELINE_RUNBOOK.md)
- **Run the examples / your own photos (multi-view, depth + ray maps, Blender):** [docs/KAGGLE_EXAMPLES.md](docs/KAGGLE_EXAMPLES.md)
- **Enhancement study (35 ideas on a frozen DA3, novelty-checked, top 3 + plan):** [docs/da3_enhancement_report.md](docs/da3_enhancement_report.md)
- **Run the enhancements and compare them with the original DA3:** [docs/ENHANCEMENTS_RUNBOOK.md](docs/ENHANCEMENTS_RUNBOOK.md) · enhancement 1 report: [reports/enhancement_1_self_audit.md](reports/enhancement_1_self_audit.md) · enhancement 2 report: [reports/enhancement_2_foveated.md](reports/enhancement_2_foveated.md)
- **Enhancement idea: DA3 for dynamic scenes (4D):** [docs/DYNAMIC_SCENES.md](docs/DYNAMIC_SCENES.md)
- Plan, paper-vs-release differences: [docs/PLAN.md](docs/PLAN.md)
- Results and status: [reports/baseline.md](reports/baseline.md) · tasks: [TODO.md](TODO.md)

## Kaggle notebooks
`notebooks/00_setup` · `01_parity` · `02_train` · `03_eval` · `04_demo_export` (+ `04_demo_export_colab` for Google Colab) · `05_self_audit` (+ `05_self_audit_colab`)
(enhancement 1) · `06_foveated` (enhancement 2) · `09_compare_all` (original DA3 vs all enhancements). They are thin wrappers:
clone this repo, install the pinned requirements, call the scripts in `scripts/`. They are
generated by `notebooks/make_notebooks.py`: edit that file, not the `.ipynb` files.

## Layout
`src/da3/` (backbone, heads, camera, geometry, losses, data, eval, export; `compare/` = shared
result records and comparison tables; `enhancements/` = one sub-package per enhancement),
`configs/`, `scripts/`, `tests/`, `notebooks/`, `docs/`, `experiments/` (registry of runs;
`experiments/results/` = standard result records), `reports/`.
